## 남은 작업 — 세 묶음

### A. 전체 소스 반영과 독립 Preview

실제 배포 원본 전체 대조 → 동봉한 전체 복구 후보를 독립 worktree/브랜치에 반영 → 최종 lockfile로 새 설치·검사 → 대상 프로젝트/브랜치를 명시한 독립 Vercel Preview. 기존 운영 프로젝트·별칭·main을 덮지 않는다. CLI 배포의 커밋 메타데이터만으로 원본 일치를 단정하지 않는다.

### B. 실제 문의 운영

접수 서비스 계정·회사 수신함·시험 전송 승인·분산 저장/중복/유실 대응·CSP/도메인/환경변수·외부 영상/글꼴·모바일 실기기·담당자/복구 절차를 확인한다. 현재 연결은 조회와 문서 쓰기가 가능하지만, 컨테이너 전체 복구 소스와 대형 미디어를 정확히 지정한 별도 배포 대상으로 옮기는 경로는 확보하지 못했다. 이것이 새 배포를 하지 않은 이유다.

### C. 사업/권리/법률 결정

사업자 정보·개인정보 문서·거래/라이선스·작품/AI/음악/상표/초상 권리·운영 응답/납품 약속·실제 시공 자료 공개 허가를 확인한다. 온라인 결제/환불/이용권/정산, 서버 인증/작가/관리자 CMS, 장치 송출 운영은 별도 설계·연결 과제로 남아 있다.
