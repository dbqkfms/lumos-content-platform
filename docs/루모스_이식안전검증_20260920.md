## 다음 입력과 실행 지점

연결 GitHub의 `user:dbqkfms lumos` 저장소 검색은 기존 두 저장소를 반환했고, Vercel 연결은 팀 정보를 반환하지 않았다. Library의 추가 ZIP은 우리 수정·검증 산출물이었고 실제 원본이 아니었다. 전 계정·전 PC에 원본이 없다고 단정하지 않는다.

**필요한 것은 BuyerProofSummary.tsx·PreviewPlayer.tsx·PrivacyPage.tsx가 들어 있는 실제 LUMOS 작업폴더 ZIP이다.** client/server/shared/scripts, package.json, 잠금파일, 공개 데이터, 빌드/라우팅 설정을 포함한다. 비밀키·.env·토큰·쿠키·node_modules·개인 문의/고객 기록은 제외한다. 대용량 영상은 원본 소스 확인 후 별도로 처리한다.

기존 `scripts/discover-lumos-source.py`와 원본 확보 실행지시는 승인된 LUMOS/Downloads 범위에서만 사용한다. 실제 PC에서 실행했다고 주장하지 않는다. 이제 원본 없이 같은 재추적이나 보조 도구 작업만 반복하지 않는다.

원본 확보→새 브랜치→실제 공개범위/신규문의/정책/포털 보존→검증된 공통수정 선택 이식→같은 원본으로 전체 검사→명시적 운영 승인 순으로 진행한다. 알려진 배포 결함을 그대로 따라 만들어 통과시키지 않는다. 의도적인 UI 변경은 이유·승인·새 테스트를 함께 남긴다.
